# Socratys

Socratys accompagne l'élève de terminale dans la rédaction de sa dissertation de philosophie,
en lui posant des questions, pour l'aider à penser par lui-même.

Page entièrement statique (HTML, CSS, JavaScript), sans compte ni serveur : les réponses de
l'élève restent dans son navigateur, rien n'est envoyé.

Conçu par Laurent Awono, professeur de philosophie.
